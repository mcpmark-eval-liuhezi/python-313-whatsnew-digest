# python-313-whatsnew-digest

Handout repository for the Python 3.13 unit: a distilled digest of the official
[What's New in Python 3.13](https://docs.python.org/3/whatsnew/3.13.html) release notes,
covering the highlights, notable deprecations, and the authoritative source page.

## Files

- **[python-313-release-notes-digest.md](python-313-release-notes-digest.md)** — the digest itself: a `Highlights` section with bullets distilled from the release notes (including PEP numbers where the page cites them), a `Notable deprecations` section, and a `Source` line naming the page read and its address.

## Repository info

This repository is a small study-group note repo for the Python 3.13 unit. Digests and follow-ups are developed on feature branches and merged through reviewed pull requests rather than pushed directly to the default branch.
